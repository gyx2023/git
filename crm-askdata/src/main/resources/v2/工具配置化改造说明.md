## 🚀 使用指南

### 1. 执行数据库脚本

```bash
# 在 OceanBase/MySQL 中执行
source script/sql/askdata_tool_config.sql
source script/sql/askdata_tool_init_data.sql
```

### 2. 启动应用

应用启动后，会自动加载新的组件。

### 3. 工作流程

**正确的调用流程：**

```
用户提问: "查询华东区上月销售额"
  ↓
HiAgent 识别意图
  → 工具名: get_sales_report
  → 参数: {region: "huadong", timeValue: "last_month"}
  ↓
返回给 Java 后端 (RouterService)
  ↓
ToolCallExecutor 执行
  → 优先从数据库获取工具配置
  → 调用 DatabaseDrivenApiTool 执行
  → 参数校验 + 转换
  → 调用原业务接口
  → 返回结果
  ↓
前端展示结果
```

**关键点：**
- ✅ HiAgent **不直接调用**后端 API
- ✅ HiAgent 只负责**识别工具和参数**
- ✅ Java 后端负责**执行工具**和**返回结果**
- ✅ 保持现有的 RouterService 流程不变

## 🔧 HiAgent 集成

### 配置 HiAgent 定时拉取 Schema

在 HiAgent 平台配置定时任务：

```
定时任务：每 5 分钟调用
GET http://your-backend.com/api/askdata/tools/schemas

自动注册返回的工具为 HTTP 插件（仅用于识别，不直接调用）
```

### 正确的调用流程

当用户提问时：

1. **HiAgent 识别意图**
   - 根据已注册的 Schema 匹配工具
   - 提取参数
   - 返回给 Java 后端：`{toolName: "xxx", entities: {...}}`

2. **Java 后端执行**
   - RouterService 接收 HiAgent 的识别结果
   - ToolCallExecutor 从数据库获取工具配置
   - DatabaseDrivenApiTool 执行工具
   - 返回结果给前端

3. **前端展示**
   - 渲染图表或表格

**关键点：**
- ❌ HiAgent **不直接调用**后端的 `/api/askdata/tool/execute`
- ✅ HiAgent 只负责**识别工具和参数**
- ✅ Java 后端负责**执行工具**

## ⚠️ 注意事项

### 1. 缓存管理

- 工具配置缓存在 Redis 中，TTL 默认 5 分钟
- 修改配置后，可以手动清除缓存：
  ```bash
  # 调用清除缓存 API（需要实现）
  POST /api/askdata/tools/cache/clear
  ```

### 2. 参数转换规则

当前实现了 `date_range_mapper` 转换器，支持：
- `last_month` → 上月日期范围
- `last_quarter` → 上季度日期范围
- `ytd` → 年初至今
- `last_week` → 上周

如需新增转换器：
1. 实现 `ParamTransformer` 接口
2. 标注 `@Component("converter_name")`
3. 在数据库配置的 `transform_rule` 字段中使用

### 3. 错误处理

- 工具配置不存在：返回 "工具配置不存在：xxx"
- 参数校验失败：返回具体的参数错误信息
- 执行失败：返回 "工具执行失败：xxx"

## 🐛 问题排查

### 问题 1：工具配置不存在

**原因：** 数据库中未配置该工具

**解决：** 检查 `askdata_tool_config` 表中是否有对应记录

### 问题 2：参数校验失败

**原因：** AI 提取的参数不符合配置要求

**解决：** 
1. 检查 `askdata_tool_param` 表中的校验规则
2. 调整 HiAgent 的 Prompt 或参数定义

### 问题 3：API 调用失败

**原因：** 原接口地址不可达或返回格式不符

**解决：**
1. 检查 `api_url` 配置是否正确
2. 检查 `response_data_path` JSONPath 是否正确
